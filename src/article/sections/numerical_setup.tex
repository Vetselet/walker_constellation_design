\subsection{Пространственная и временная дискретизация}
\label{subsec:coverage_discretization}

Для численной оценки область $\mathcal{R}$ заменяется сеткой H3 заданного
разрешения. Обозначим через
\begin{equation}
    \mathcal{Q}_{\rho}=\{Q_1,\ldots,Q_{N_{\rho}}\}
    \label{eq:h3_point_set}
\end{equation}
множество центров H3-сот разрешения $\rho$, выбранных для рассматриваемой
области. Для дискретной проверки покрытия усредним
индикатор~\eqref{eq:coverage_indicator} по этим точкам:
\begin{equation}
    \widehat{\mu}_{\rho}(t,\mathbf{x})=
    \frac{1}{N_{\rho}}\sum_{j=1}^{N_{\rho}}
        \chi(Q_j,t,\mathbf{x}).
    \label{eq:discrete_coverage_metric}
\end{equation}
Этот показатель представляет долю покрытых расчётных точек. Для оценки
доли площади из~\eqref{eq:coverage_metric} вклады точек необходимо взвешивать
по площадям представляемых ими участков области $\mathcal{R}$.
При проверке покрытия всех расчётных точек такие веса не влияют на результат.
Значение $\widehat{\mu}_{\rho}(t,\mathbf{x})=1$ означает, что в момент $t$
покрыты центры всех выбранных H3-сот. Результат такой оценки зависит от
разрешения $\rho$: его увеличение повышает пространственную детализацию
проверки, но требует существенно больших вычислительных затрат.

Для проверки покрытия во времени на интервале $\mathcal{T}$ задаётся конечная
расчётная сетка
\begin{equation}
    \begin{gathered}
        \mathcal{T}_M=\{t_0,t_1,\ldots,t_M\}\subset\mathcal{T},\\
        t_{\mathrm{start}}=t_0<t_1<\cdots<t_M=t_{\mathrm{end}}.
    \end{gathered}
    \label{eq:time_grid}
\end{equation}
Здесь $M\in\mathbb{N}$ -- число временных промежутков, так что сетка
$\mathcal{T}_M$ содержит $M+1$ расчётных моментов и включает оба конца интервала
$\mathcal{T}$. Начальная эпоха, границы интервала, модель движения и узлы сетки
$\mathcal{T}_M$ задаются до начала численного решения. Расстояния между
соседними моментами времени выбираются
с учётом характерных угловых масштабов построения, включая расстояние между
соседними КА и ширину полосы покрытия. В результате условие покрытия из
задачи~\eqref{eq:optimization_problem} проверяется в дискретном виде:
\begin{equation}
    \min_{t\in\mathcal{T}_M}
        \widehat{\mu}_{\rho}(t,\mathbf{x})=1.
    \label{eq:discrete_time_coverage}
\end{equation}
Это условие означает, что во все моменты расчётной сетки покрыты все
выбранные центры H3-сот. Покрытие между расчётными точками и моментами
времени требует отдельной проверки.
